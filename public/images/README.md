# Изображения проекта

Сюда можно добавить работы из Photoshop:

- `game-cover.webp` — обложка игры, рекомендуемый размер 1600×900;
- `avatar.webp` — аватар автора, рекомендуемый размер 800×800;
- `project-cover.webp` — обложка нового проекта, рекомендуемый размер 1200×750.

Для сайта лучше экспортировать изображения в WebP. Исходники PSD храните отдельно или в папке `design`, если правила репозитория это позволяют.
